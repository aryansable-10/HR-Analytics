# HR Analytics Project 📊

This project focuses on analyzing employee attrition using Python, Pandas, Seaborn, and Matplotlib. The goal is to identify the major factors influencing employee turnover and help HR departments make data-driven decisions to improve employee retention.

## 🚀 Features

* Data Cleaning & Preprocessing
* Exploratory Data Analysis (EDA)
* Employee Attrition Analysis
* Visualization using Seaborn & Matplotlib
* Insights on:

  * Job Satisfaction
  * Promotions
  * Workload
  * Monthly Hours
  * Tenure in Company
  * Salary Levels

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## 📈 Key Insights

* Employees with very low or very high project counts show higher attrition.
* Lack of promotion significantly increases resignation chances.
* High workload and long working hours contribute to employee turnover.
* Satisfaction level plays a major role in employee retention.

## 📂 Dataset

The dataset contains employee-related information such as:

* Satisfaction Level
* Last Evaluation
* Number of Projects
* Average Monthly Hours
* Time Spent in Company
* Promotion Status
* Department
* Salary
* Attrition Status

## ▶️ How to Run

1. Install required libraries:

```bash
pip install pandas numpy matplotlib seaborn
```

2. Run the Python file:

```bash
python hr_analytics_march.py
```
